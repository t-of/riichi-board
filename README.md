# RIICHI BOARD — 卓に置く麻雀の点数計算

麻雀の卓の真ん中に置く、点数計算と持ち点の表示盤。翻と符を押すと点数と「誰が誰にいくら払うか」が出て、確定すると 4 人の持ち点・本場・供託が自動で動く。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/riichi-board/
- 制作: [T.OF...](https://t-of.github.io/)

麻雀 点数計算・点数表・持ち点・符計算（Riichi Mahjong score calculator）。

## 遊び方

1. スマホを卓の真ん中に平らに置く。4 辺に 4 人の持ち点が、それぞれの人の向きで出る（画面の回転をロックしてから置くとよい）。
2. リーチした人は、自分の辺の「リーチ」を押す（1000 点が供託に移る）。
3. 局が終わったら、真ん中の「あがり」か「流局」を押す。あがった人・放銃した人・翻・符を押して確定すると、点数が自動で動く。
4. 間違えたら「戻す」。1 回前の状態にちょうど戻る。

パネルを押すと、そのパネルの向きのままほかの 3 人との点差を 3 秒出す。メニューから「点を直す」（持ち点・本場・供託・親を手で書き換える）、設定（音・切り上げ満貫）ができる。
役の判定はしない（翻と符は人が数える）。ダブロン・トリロン・チョンボ・ウマ/オカ・三人打ちは入れていない（起きたら「点を直す」で合わせる）。お金への換算・レート・精算の機能は入れていない。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## データ

| キー | 中身 |
|---|---|
| `riichi-board.settings` | `{ v: 1, sound, length: 'hanchan' \| 'tonpu', start, kiriage, names: [4] }` |
| `riichi-board.game` | 途中の対局: `{ v: 1, scores: [4], startDealer, dealer, round, honba, kyotaku, riichi: [4], hands, ended, undo: [最大50] }`。ブラウザを閉じても「続きから」で戻れる |

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 0 --bind 127.0.0.1   # 出た番号で http://127.0.0.1:<番号>/
node tools/test.js                          # 点数計算・持ち点の動きの自己チェック
```

| ファイル | 中身 |
|---|---|
| `js/score.js` | 点数の決まりごと（DOM に触らない）。翻・符から基本点、ロン・ツモ・流局・リーチ・戻すを状態に当てる関数 |
| `main.js` | 画面・操作・音・保存 |
| `tools/test.js` | 自己チェック（点数の表と持ち点の動きの例 A〜H を照らす） |
